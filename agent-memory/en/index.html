Source notes · Seven project articles

Long-term memory is more than vector search

An agent should not pour all history back into its prompt. It needs to know who stores raw history, user profiles, graph relationships, workflow state, and current model input; when each is written; and how each returns. The series asks those same questions of eight projects.

How to read: begin with the route notes and its five boxes, then move project by project. For system selection, ask where history lives before asking how clever retrieval is.
