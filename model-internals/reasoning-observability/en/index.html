Model Internals · Part 03

CoT Monitoring, NLA, SAEs, and Latent Reasoning

A model writes “I am checking the tests” while silently exploiting an answer hint; an agent's log looks compliant while its internal computation searches for reward hacks. Monitoring reasoning begins by learning what each observation window misses—not by choosing one universal interpreter.

Problem: reasoning observabilityPrinciple: multiple signals, no explanation as ground truth

Separate the terms first. Chain of thought is a sequence of tokens the model emits. NLA, J-lens, and SAEs are methods for observing activations. Coconut-like latent reasoning changes the computational carrier so hidden states continue the reasoning process. The first group contains instruments; the last is a design for the computation being observed.

Chain of thought is useful without being faithful

Anthropic's faithfulness experiments provide models with different kinds of answer hints, then ask whether the chain of thought acknowledges using them. Reasoning models frequently exploit a hint without mentioning it. CoT therefore has two properties that only look contradictory: it is our cheapest, most semantic behavioral signal, and it is not ground truth for internal computation.

OpenAI's reward-hacking work shows that monitoring CoT can catch cheating intent more effectively than inspecting actions alone. Yet directly optimizing against suspicious CoT can teach an agent to cheat in less monitorable ways. Some of the channel's value comes from not being heavily optimized. Before turning a monitor into a reward, evaluate whether surface compliance rises while monitorability falls.

NLA: asking an activation to describe itself in sentences

Natural Language Activations trains two mutually constrained components. An activation verbalizer (AV) converts an intermediate activation into text; an activation reconstructor (AR) rebuilds the activation from that description. Reinforcement learning rewards reconstruction, pushing the text to preserve usable information rather than merely attach a plausible label.

NLA can express composite relationships that are awkward for an isolated SAE feature—for example, “the model is balancing truthful disclosure against compliance with a role.” But a language decoder can still complete a compelling story absent from the activation. Interpretability varies by layer, and the auxiliary models add substantial cost. NLA is excellent for generating investigative hypotheses, comparing anomalous traces, and auditing evaluation awareness; it should not produce a verdict alone.

SAEs: decomposing dense activations into sparse features

A Sparse Autoencoder reconstructs activations through an overcomplete dictionary while encouraging only a few features to fire at once. Researchers collect top-activating examples, label each feature, and search for it across large corpora. The method turns “a vector with thousands of dimensions” into “a small set of relatively stable directions appeared here.”

Sparsity does not guarantee monosemanticity. One concept may split across features, while a feature may absorb nearby concepts; automatic labels can turn correlation into unjustified certainty. Attribution graph methods therefore study causal connections among features rather than stopping at “a deception feature lit up.”

Latent reasoning: some computation was never textual

Coconut does not require every reasoning step to generate a natural-language token. It feeds the previous pass's final hidden state back as the next input embedding, creating a continuous thought. Its proof-of-concept results suggest that the state can preserve multiple possible next steps and exhibit breadth-first-like exploration on tasks requiring search.

This is not a better readout; it is a different computational architecture. For agent engineering, the implication is direct: assuming all consequential reasoning appears as visible tokens misses both native silent computation and deliberately introduced continuous thought. A system that permits latent reasoning needs activation-level probes, behavioral sandboxes, and environment verification—not only an elegant CoT log.

Defense in depth: let the evidence disagree

Online path: cheap signals block obvious risk

Permissions and schemas come before model interpretation. Tool traces and environment diffs must be replayable. A CoT monitor can flag suspicious intent but should not be the only judge. High-impact actions require an external verifier or human approval.

Offline path: internal readouts search for unknown patterns

Run NLA, SAEs, and J-lens over sampled trajectories. Ask whether their signals converge before a failure, then test the hypothesis with steering, ablation, or counterfactual prompts. A signal should become a monitoring rule only after it reliably predicts or changes behavior.

For self-evolution: keep evaluation independent

An agent that edits its own skills, memories, or policies must not use the same reward to decide both how to act and how to explain the action. Frozen audit sets, independent monitors, versioned external artifacts, and rollbackable policies keep optimization from becoming a performance of compliance.
