Go 从请求到生产现场

如果你只会写一点 Go，也可以从这里开始。全系列只跟一件事：一个小服务收到请求后，同时抓取几个网页，再把结果汇总成 JSON。 我们先看代码“发生了什么”，再解释为什么会复制、等待、分配和复用连接，最后才进入标准库与 runtime 源码。

先把例子想成一张代办单：调用方交来两个网址；服务分别访问它们；两个结果回来后，服务再合成一份 JSON。 第一遍只跟“谁接到任务、谁开始工作、谁在等待、谁把结果交回来”；第二遍再把这些动作对应到标准库与 runtime 的名字。

两遍读法：如果你只学过变量、函数、结构体和基本循环，先读总路线前两节，再读每篇开头的请求回放与结论； 源码字段、队列细节和诊断实验可以留到第二遍。八篇仍建议按值语义、调度、并发、抽象、取消、内存、连接与诊断顺序阅读。
