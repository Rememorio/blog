Agent 框架源码阅读系列

这个系列不做框架排行榜，而是跟着一次 Agent 运行逐项追问：谁调用模型，谁执行工具，状态写到哪里， 哪些操作要先授权，步骤和多个 Agent 又怎样衔接。前五篇先建立比较方法；中间五篇用 ADK、Agno、AutoGen、 CrewAI 与 Eino 展开不同取舍；最后三篇沿 tRPC-Agent-Go 的上下文、Memory 和 Evolution，分别处理当前会话、跨会话知识与未来可复用的 Skill。

源码链接固定到文中标注的公开快照，产品定位以项目 README 与官方文档为准。每篇都固定一个请求或任务，按“输入如何进入、哪个组件改变状态、读者能看到什么结果、失败会留下什么影响”的顺序阅读。
