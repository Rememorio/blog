Source notes · Seven-part route

How Hermes Agent runs, learns, and delivers

The series keeps one repair task in view: first follow a request through the model, tools, and state; then see how delivered work becomes candidate experience, a new or revised Skill, and finally an adoption decision backed by independent evidence.

Recommended order: Parts I–IV establish the runtime and learning path. Parts V–VII explain data roles, capability revision, and what must be true before a change counts as delivered.
